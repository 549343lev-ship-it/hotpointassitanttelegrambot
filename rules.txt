## АБРЕВІАТУРИ ФІТИНГІВ (PPR з латунню)
МРЗ/МРН = муфта різьба ЗОВНІШНЯ | МРВ = внутрішня | КРЗ/КРН = коліно зовн. | КРВ = внутр.
2 параметри (25х3/4) = муфта/коліно з різьбою; 3 параметри (20х16х20) = ТРІЙНИК.
Логіка різьб: Кран ВВ → потрібна МРЗ; Кран ВЗ → МРВ. Діаметр 16 → скоріш PUSH.
ЗР = зовнішня різьба (=МРЗ) | ВР = внутрішня (=МРВ).
Ду15/Dn15=1/2" | Ду20=3/4" | Ду25=1" | Ду32=1 1/4" | Ду40=1 1/2" | Ду50=2".
Різьби: 1/4"=DN8 | 3/8"=DN10 | 1/2"=DN15 | 3/4"=DN20 | 1"=DN25 | 1 1/4"=DN32 | 1 1/2"=DN40 | 2"=DN50.

## ТРІЙНИКИ НАМАЛЬОВАНІ
Майстри малюють трійник різними способами — всі варіанти означають ТРІЙНИК:
  ⊥ (перевернуте Т)  → ТРІЙНИК
  Т-подібний символ  → ТРІЙНИК
  Y-подібний символ  → ТРІЙНИК (трійник-Y або трійник похилий)
  3 лінії від точки  → ТРІЙНИК
  «тр» поряд з розмірами → ТРІЙНИК
Якщо поряд є 2 однакових розміри + 1 інший (наприклад 110х110х50) → трійник редукційний.
Якщо всі три однакові (110х110х110) → трійник рівний.
Приклад: ⊥110х110х50 → "Трійник канал ф110х110х50 87 ASG" (категорія sewage).
Приклад: Т25х16х25 → "Трійник PPR ф25х16х25 Ekoplastik" (категорія plastic_ppr).

## ПЕРЕХІДНИКИ ЛАТУНЬ (НЕ ПАЙКА!)
⚠️ ВАЖЛИВО: "перехідник", "перехід", "перехідна фасонина", "футорка", "ніпель", "муфта різьба"
з розмірами типу 3/4"х1/2" або 1"х3/4" — це ЛАТУННІ ПЕРЕХІДНИКИ, категорія adapters_reducers.
НЕ плутати з PPR-муфтами! Латунні перехідники — металеві, з різьбою на обох кінцях.
Ознаки латунного перехідника: два розміри-різьби (1/2"х3/4", 1"х1/2"), або слова:
футорка / ніпель редукційний / муфта редукційна / МРЗ без PPR / штуцер / подовжувач різьби.
Правило: якщо немає слова PPR/ПП/пайка — це НЕ пайка, це латунь → adapters_reducers.
Приклади правильні:
  "перехід 3/4х1/2" → "Ніпель редукційний 3/4"х1/2" RAFTEC", adapters_reducers
  "футорка 1"х3/4"" → "Футорка 1"х3/4" RAFTEC", adapters_reducers
  "муфта 25х3/4" БЕЗ слова PPR → "Муфта РР RAFTEC 25х3/4" або латунна, НЕ PPR

## ШЛАНГИ ДЛЯ ВОДИ (гнучка підводка)
⚠️ "шланг", "шлангова підводка", "підводка", "гнучка підводка" для сантехніки (до змішувача,
до унітазу, до бачка, до раковини) = категорія ШЛАНГИ (hoses), виробник RAFTEC Rhein.
НЕ плутати з:
  - садовим шлангом / шлангом для поливу → це садовий, категорія other, не підбираємо
  - Ecoflex/екофлекс → це утеплена труба для теплопостачання, НЕ гнучка підводка
  - Армованим шлангом для насоса/компресора → industrial, не підбираємо
Гнучка підводка: різьба M10 (стандарт), 1/2", 3/8"; довжини 30–200 см; матеріал нержавійка/поліамід.
Правильна нормалізація: "Підводка гнучка 1/2"х50см нерж. RAFTEC Rhein"
Пріоритет: Raftec Rhein в поліаміді → Raftec Rhein → MATEU (Spain)

## ПЛАНКИ МОНТАЖНІ (водорозетки)
Планка монтажна / шоколадка / п'ятак / монтажне коліно / вухань / водорозетка —
це настінний елемент для підключення змішувача до стіни:
  Одинарна водорозетка з вушками (вухаста) = Водорозетка настінна 1/2" (одинарна)
  Подвійна планка 150мм = Монтажна планка 150мм для змішувача 1/2"
  "шоколадка", "п'ятак", "планка" → "Монтажна планка 150мм 1/2" для змішувача"
Категорія: adapters_reducers або shutoff_valves (де є в каталозі).
Водорозетка за замовчуванням → ОДИНАРНА настінна з вушками (вухаста).
Подвійна водорозетка (планка) → для підключення змішувача (2 отвори на 150мм).

## КОЛІНА МОНТАЖНІ (настінні коліна, водорозетки з вушками)
"Монтажне коліно", "коліно настінне", "вухань", "вушко", "водорозетка", "L-подібне з вушками" —
це настінне коліно (кутовий вивід) з отворами під кріплення:
  Нормалізація: "Водорозетка настінна 1/2" кутова" або "Коліно настінне 1/2" з вушками"
  Для PPR: "Водорозетка кутова PPR 20х1/2" Ekoplastik" (вбудовується в стіну при пайці)
  Для PUSH: "Водорозетка PUSH 16х1/2" Raftec"
  Для різьби: "Коліно МРЗ настінне 1/2"" (латунне)
Категорія: plastic_ppr (для PPR), push_systems (для PUSH), adapters_reducers (для різьбових).

## PUSH (натяжна система PEX-A)
МАРКЕРИ: пуш/push/натяжн/PEX/пекс/ГІЛЬЗ — слово "гільзи" в списку = ВСЕ замовлення PUSH.
Голі розміри БЕЗ маркерів = НЕ push. "⊥110" = трійник каналізації, НЕ натяжний!
Відповідність PUSH↔PPR: PUSH16≈PPR20 | PUSH20≈PPR25 | PUSH25≈PPR32 | PUSH32≈PPR40 | PUSH40≈PPR50.
Кути PUSH: тільки 90° (45° у PUSH не існує!). ПЕ/ПНД затискні: 20–63 мм.
Назви: "Кутник натяжний ф25х25 PUSH RAFTEC" | "Трійник натяжний ф25х16х25" | "Гільза натяжна ф16".
⚠️ Гільза натяжна ≠ прес-кільце ≠ насувна гільза!
⚠️ НЕ додавай гільзи до фітингів — бот порахує ПІСЛЯ підбору:
  трійник=3 виходи; коліно=2; муфта без різьби=2; МРЗ/МРВ=1; заглушка=1; євроконус=1.

## "+ ІЗОЛ" (утеплювач до труби)

## КАРАКУЛІ МАЙСТРІВ
⊥ / Т-вилка / Y / три лінії від точки = ТРІЙНИК.
  Приклад: ⊥110х110х50 → "Трійник канал ф110х110х50 87 ASG"
  Приклад: ⊥25х16х25 (PPR контекст) → "Трійник PPR ф25х16х25 Ekoplastik"
∠ / L = КОЛІНО: "∠110х45" → Коліно канал 110 45.
-//- / —//— / «теж» = ПОВТОР ТИПУ з попереднього рядка.
Рядок без типу ("х45=10шт", "ф50х1м") = ПРОДОВЖЕННЯ попереднього типу.
